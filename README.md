# PREMIUM UA — сайт гільдії Free Fire

## Як опублікувати через GitHub Pages
1. Розпакуй `premium-ua-github-pages.zip`.
2. Увійди на GitHub і створи новий репозиторій, наприклад `premium-ua`.
3. Завантаж у репозиторій `index.html` та всю папку `assets` (структуру папок не змінюй).
4. Відкрий **Settings → Pages**.
5. У розділі Build and deployment вибери **Deploy from a branch**, гілку `main` і папку `/ (root)`, натисни **Save**.
6. Через кілька хвилин GitHub покаже адресу сайту в тому ж розділі Pages.

## Що вже є
- Адаптивний темний дизайн із червоними акцентами та анімаціями.
- Головний екран з наданим зображенням PREMIUM UA.
- Засновники та посилання на Telegram.
- Розділ «Про нас» з історією гільдії.
- 11 карток учасників, створених зі сторінок наданого PDF.
- Правила вступу, Guild Wars, рейтинг за тиждень/місяць і контакти.
- Кнопки Telegram-каналу та TikTok.

## Що потрібно додати пізніше
Guild Wars та рейтинг наразі показують чесні повідомлення-заповнювачі, бо результати й очки не були надані. Надішли дані — і їх можна буде додати в сайт.
